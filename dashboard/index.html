How the value is built — model radar-2

Every number below comes from the sealed snapshot's own figures. No protocol name is ever special-cased: the same function scores every row.

implied value = TVL × 0.30 × growth × maturity × precedent × reach

  • Base: TVL × 0.30. A launch is valued at three-tenths of the value already locked in the protocol.
  • Growth: 1 + (7-day TVL change, clamped to −50%…+100%) × 0.6. A protocol gaining users is worth more than a flat one; a shrinking one is worth less.
  • Maturity: 0.70 + min(age in days, 730) / 730 × 0.30. A protocol that has run up to two years with no token has a longer track record and a larger user base to reward. Unknown listing date counts as 365 days.
  • Precedent: 0.85 + launch-rate(category) × 0.30. The launch rate is the share of the snapshot's protocols in that category that already record a token — read off the snapshot itself, not written by hand. Categories whose peers have mostly launched (Lending, Dexs) score above categories where almost nobody has (Risk Curators). Small categories and protocols with no category use the snapshot's global rate.
  • Reach: 1 + 0.02 × chains (up to 5). A protocol live on more chains reaches more farmers.

What the board covers

The board ranks every protocol on the snapshot's watchlist — 40 protocols at or above $50M TVL that record no token and are not a wrapped, staked or bridged product of one that trades — plus every other rankable pre-token protocol below the floor. A protocol below the floor is no worse a subject than one on it: the watchlist is a floor, never a ceiling.

Words that matter

The board says a protocol records no token, never that it has none: the snapshot is DefiLlama's record, not proof, and a protocol on the list may still have a token its record does not carry. An implied value is this radar's own claim, never a promise — it does not predict whether or when a token is issued.

Farm plans

Every row carries six steps built from the protocol's own record — its category, its chains, its TVL and its age — each with what it costs and how long it takes. The first step is always a fresh wallet; the last is always a farm log. A real airdrop never asks you to pay to claim.
